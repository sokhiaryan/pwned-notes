# pwned-notes

A personal collection of CTF challenges, notes, writeups, scripts, and research,
organized by category and platform. This is a long-term, continuously updated
archive of my work solving security challenges.

## Categories

- `web/` — web exploitation
- `reverse-engineering/` — binary and code reversing
- `pwn/` — binary exploitation
- `crypto/` — cryptography
- `forensics/` — digital forensics
- `blockchain/` — smart-contract / web3 security
- `hardware/` — hardware & microarchitecture
- `active-directory/` — Active Directory attack & DFIR
- `osint/` — open-source intelligence
- `mobile/` — mobile application security
- `cloud/` — cloud security
- `misc/` — everything else

## Platforms represented

- Lunar CTF (Lun4R) — see [Lunar CTF 2026 Finals](LUNAR-CTF-2026-FINALS.md)
- Kaspersky CTF
- picoCTF

## Structure

Challenges are organized as `<category>/<platform>/<challenge>/`, containing
whatever combination of notes, writeups, scripts, exploits, and other artifacts
the challenge produced. Example:

```
forensics/
└── hack-the-box/
    └── admin/
        ├── notes.md
        └── exploit.py
```

## Note

This repository is continuously updated as new challenges are solved.
